Usage
=====

To use this module, you need to:

1. Have Manager rights for Project group to create project statuses.
2. Go to *Project > Configuration > Project Statuses*.
3. When creating a project or editing it, select the status

Bug Tracker
===========

Bugs are tracked on `GitHub Issues <https://github.com/tawasta/oca-backports/issues>`_.
In case of trouble, please check there if your issue has already been reported.
If you spotted it first, help us to smash it by providing a detailed and welcomed
`feedback <https://github.com/tawasta/oca-backports/issues/new?body=module:%20project_status%0Aversion:%2019.0%0A%0A**Steps%20to%20reproduce**%0A-%20...%0A%0A**Current%20behavior**%0A%0A**Expected%20behavior**>`_.
